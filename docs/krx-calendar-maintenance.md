# KRX 캘린더 연간 갱신·검증 절차

`src/services/krx_calendar.py`는 런타임 외부 조회를 하지 않는 수동 검증
캘린더다. `SUPPORTED_KRX_CALENDAR_YEARS`에 없는 연도의 평일과
`KRX_UNCERTAIN_SESSION_DATES`의 날짜는 신규 매수를 fail-closed 한다.
감시 루프와 보호매도, Tier-1 손절, 주문취소는 계속 허용한다.

## 갱신 시점

다음 연도 거래소 일정이 공지된 뒤, 늦어도 현재 지원 연도의 마지막
거래일 전까지 갱신한다. 임시공휴일, 선거일, 재난·시스템 사유 임시휴장,
수능일 거래시간 변경 등 수시 공지도 운영 중 확인한다.

## Source of truth

반드시 한국거래소의 해당 연도 공지와 대한민국 공식 공휴일 자료를 사람이
대조한다.

- KRX 보도자료/시장운영 공지: 연말 휴장일, 다음 해 최초 개장일과 시간
- KRX/KIND 기타시장안내: 수능일 등 임시 거래시간
- 인사혁신처·관보: 공휴일, 대체공휴일, 임시공휴일
- 중앙선거관리위원회: 법정 선거일
- KRX 일반 시장 규정: 토요일, 공휴일, 근로자의 날, 연말 휴장 원칙

뉴스 기사나 포털 캘린더는 발견용으로만 쓰고 최종 검증 근거로 쓰지 않는다.
공식 공지가 아직 없으면 정상장으로 추정하지 말고 해당 날짜를
`KRX_UNCERTAIN_SESSION_DATES`에 둔다.

## 변경 순서

1. 새 연도의 모든 평일 휴장일을 `KRX_WEEKDAY_HOLIDAYS`에 추가한다.
   연말 휴장일과 근로자의 날을 빠뜨리지 않는다.
2. 정규장 시간이 09:00–15:30과 다른 것으로 확정된 날짜를
   `KRX_SPECIAL_SESSIONS`에 개장·폐장 시각과 공지 사유로 추가한다.
3. 수능일처럼 특별장이 예상되지만 주식 정규장 시간이 아직 공식 확인되지
   않은 날짜를 `KRX_UNCERTAIN_SESSION_DATES`에 추가한다. 공식 확인 뒤
   특별장 또는 정상장으로 분류하기 전까지 제거하지 않는다.
4. 공휴일, 특별장, 불확실 날짜의 상호 중복과 해당 연도 범위를 검토한다.
5. 마지막으로만 새 연도를 `SUPPORTED_KRX_CALENDAR_YEARS`에 추가한다.
   지원 연도 선언이 데이터 입력보다 먼저 들어가면 누락 평일이 매수 허가로
   바뀐다.
6. 검토한 공지 제목·발행일·URL을 변경 설명에 남기고 다른 검토자가 날짜와
   시간을 원문과 대조한다.

## Mock 검증

실계좌나 주문 API를 호출하지 않고 다음을 실행한다.

```bash
uv run pytest -q tests/test_krx_calendar.py tests/test_daily_risk.py tests/test_watcher.py
uv run pytest -q
```

최소 검증 사례:

- 지원 연도의 평일, 주말, 공휴일, 연말 휴장일
- 확정 특별장의 개장 직전/개장/폐장 직후
- 미확정 특별장이 `uncertain`이고 신규 매수만 차단하는지
- 지원 연도 12월에서 미지원 연도로 넘어갈 때 `resets_on=null`인지
- latch 재기동 보존과 다음 확정 거래일 reset
- 불확실 상태에서도 보호매도, Tier-1 손절, 주문취소가 동작하는지

외부 공식 데이터 자동수집이나 런타임 네트워크 fallback은 별도 설계·검증
없이는 추가하지 않는다.

## 현재 2026 데이터의 한계 (2026-07-26 기준)

- 지원 연도는 2026 하나뿐이다.
- 2026-01-02는 KRX의 연초 개장식 공지에 따라 정규장
  10:00–15:30 특별장으로 등록했다.
- 2026-12-31은 KRX 연말 휴장 원칙에 따라 휴장일로 등록했다.
- 교육부가 2027학년도 수능일을 2026-11-19로 확정했지만, 이 문서 작성
  시점에는 해당일 KRX 주식 정규장 시간의 공식 검증을 마치지 못했다.
  따라서 정상장 시간을 추정하지 않고 `KRX_UNCERTAIN_SESSION_DATES`에
  유지한다.
- 외부 공식 데이터의 자동수집·자동갱신은 구현하지 않았다. 새로운 임시
  휴장이나 당일 긴급 시장운영 변경은 코드가 자동 발견하지 못한다.
